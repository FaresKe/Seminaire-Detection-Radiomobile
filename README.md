# Séminaire — Détection des signaux radiomobiles

ESP32-based detection of WiFi and Bluetooth signals for a radiomobile signal detection seminar.

Projet de séminaire portant sur la détection des signaux
émis par les téléphones mobiles dans une salle de classe.

## Technologies étudiées

- WiFi
- Bluetooth Low Energy (BLE)
- 3G / 4G (étude théorique)

## Matériel

- ESP32
- Antennes WiFi/BLE
- Smartphones pour les tests

## Fonctionnalités

Le système permet notamment de :

- détecter des appareils WiFi ;
- détecter des appareils BLE ;
- mesurer le RSSI ;
- estimer approximativement la distance ;
- étudier la localisation des appareils à partir de plusieurs points de mesure.

## Codes sources

### WiFi
- Calibration RSSI
- Détection WiFi

### BLE
- Calibration RSSI
- Détection BLE

### Système combiné
- Détection WiFi + BLE
